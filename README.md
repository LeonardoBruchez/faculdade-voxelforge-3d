# VoxelForge 3D

Trabalho de Desenvolvimento Web - ADS, 2º semestre.

Fizemos uma loja virtual de peças impressas em 3D, com vitrine de produtos, carrinho, cupom de desconto e botão de finalizar compra. Usamos só HTML, CSS e JavaScript, sem framework.

- Leonardo Cassiano Bruchez Pereira

## Como rodar

É só baixar o projeto e abrir o `index.html` no navegador.

```
index.html
css/style.css
js/script.js
assets/        (imagens)
```

## Cupons pra testar

- `DESCONTO10` - 10% de desconto
- `MENOS20` - R$ 20 de desconto (compra a partir de R$ 100)
- `FRETEGRATIS` - frete grátis

## O que usamos

**HTML:** imagens, listas (`ul` e `ol`), formulário de contato e campo de cupom, tabela do carrinho, links internos e externo.

**CSS:** classes e ids, bordas, cores e fontes, estilo de texto, modelo de caixa, float (header e painel do carrinho), formatação de links (`:link`, `:visited`, `:hover`, `:active`) e position (`fixed`, `relative`, `absolute`).

**JavaScript:** variáveis, operações matemáticas e lógicas, funções, eventos (`click`, `input`, `change`, `submit`, `keydown`), DOM, `if/else` e `switch`, `for`, `for...of` e `forEach`, tipos de dados e arrays (`find`, `push`, `filter`, `splice`, `reduce`).

**Desafio do carrinho:** cupom de desconto (`aplicarCupom()`) e botão de compra (`finalizarCompra()`).
